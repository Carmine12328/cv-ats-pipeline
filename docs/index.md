# CV ATS Pipeline Documentation

Welcome to the documentation for the CV ATS Pipeline! This project is a simple yet powerful data-driven resume generator. It converts a single YAML configuration file into a beautiful, ATS-optimized PDF, a web-friendly HTML file, and a plain-text file.

## Why use this project?

When applying for software engineering or developer roles, Applicant Tracking Systems (ATS) automatically parse your CV. Complex layouts, multiple columns, and graphical skill bars often confuse these parsers, leading to missing data. 

This project solves this by ensuring your resume is:
1. **Machine Readable:** Single column, standard typography, text-first.
2. **Beautiful:** Clean, professional styling with proper margins for A4 printing.
3. **Easy to Maintain:** You only edit a single `data/cv.yaml` file instead of fighting with Word or Google Docs layouts.
